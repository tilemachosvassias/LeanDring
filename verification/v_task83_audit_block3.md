### 4.2  **(H3) CLOSED — a closed-form proof of `R_n(m) > 1`**

v_task59 names this its sharpest debt.  It is not hard, and it also
delivers the *upper* half (which the note never had), so `(J5)` no longer
rests on any numerical evidence at all.

> **Lemma J5-CF [PROVEN, this audit].**  For all `n ≥ 3` and all integers
> `m ≥ 2`, with `x = 1/m` and `u = x^n ≤ 1/8`,
> ```
>          1 + 0.73 u²  ≤  R_n(m)  ≤  1 + 1.17 u² ,
> ```
> hence `bracket < c = bracket·R_n(m) < bracket + 1`: **`c` is never an
> integer**, for every `n ≥ 3` and every `m ≥ 2`.

*Proof.*  Both products have `m`-degree `(2n−1)n(n+1)` (verified for
`3 ≤ n ≤ 14`), so
`R_n = ∏_{i=1}^{n}(1−x^{2i(2n−1)}) / ∏_{k=2}^{2n}(1−(−1)^k x^{kn})`.

*Numerator.*  `2i(2n−1) ≥ 4n−2 ≥ 3n` for `n ≥ 2`, so
`NUM ≥ 1 − ∑_{j≥1} x^{j(4n−2)} = 1 − x^{4n−2}/(1−x^{4n−2}) ≥ 1 − u³/(1−u³)
≥ 1 − 1.002 u³` (using `1/(1−u³) ≤ 1.002` at `u ≤ 1/8`).

*Denominator.*  The `k=2` factor is `(1−u²)`; even `k ≥ 4` factors are
`≤ 1`; odd factors are `(1+u^k)`.  So
`DEN ≤ (1−u²)∏_{k≥3}(1+u^k) ≤ (1−u²)·exp(u³/(1−u)) ≤ (1−u²)(1+1.145u³)
≤ 1 − u² + 1.145u³` (the `exp` bound checked at `u = 1/8, 0.1, 0.05, 0.01,
0.001`).

Hence `NUM − DEN ≥ u² − 2.147u³ = u²(1 − 2.147u) ≥ 0.7316 u² > 0` for
`u ≤ 1/8`, which holds since `n ≥ 3, m ≥ 2 ⟹ u = m^{−n} ≤ 1/8`.
For the upper half, `DEN ≥ ∏_{k=2}^{2n}(1−u^k) ≥ 1 − u²/(1−u)` and
`NUM ≤ 1`, so `R_n ≤ (1−u)/(1−u−u²) ≤ 1 + 1.17u²`.  Finally
`bracket ≤ 2n` and `2n·1.17·2^{−2n} < 1` for `n ≥ 3`. ∎

Machine confirmation of **every inequality in the proof** for
`3 ≤ n ≤ 14` and 12 values of `m`: all pass; the worst realised normalised
margin is `0.733867` at `(n,m) = (3,2)`, against the proof's guaranteed
floor `0.7316` — i.e. the bound is essentially tight and the extremal case
is exactly the note's headline row.

**⇒ v_task59 (H3) can be struck.**

### 4.4  The infinite exceptional family `m(PSp_{2n}(2)) = 2^{n−1}(2^n−1)`

Verified **directly in GAP** (not from `Maxes` tables): the subgroup
`GO^ε(2n,2) ≤ Sp(2n,2)` has index `2^{n−1}(2^n − ε)`:

```
 Sp(6,2)  : [Sp : GO^-] = 28   = 2^2(2^3-1)   [Sp : GO^+] = 36  = 2^2(2^3+1)
 Sp(8,2)  : [Sp : GO^-] = 120  = 2^3(2^4-1)   [Sp : GO^+] = 136
 Sp(10,2) : [Sp : GO^-] = 496  = 2^4(2^5-1)   [Sp : GO^+] = 528
```
and stored `Maxes` independently give the smallest indices
`S6(2): [28,36,63,120,135,315]`, `S8(2): [120,136,255,…]`.  **The family
is real and the formula is right for `n = 3,4,5`.**

**Does "carried conservatively, `b` unchanged" hide a hole?  Almost, but no.**
The note's own justification (`m/[S:P₁] → 1/2`, so `deg_q ι = 2n−1` is
unchanged) is *not quite* the whole story, because `ι` also appears as a
**lower** bound `ι(S) > q^b` inside Lemma EQ′ and Lemma Z, and at `q = 2`

```
        iota / q^b  =  2^{n-1}(2^n-1) / 2^{2n-1}  =  1 - 2^{-n}
                    =  0.875 (n=3) , 0.9375 (n=4) , 0.96875 (n=5) , -> 1
```
so `ι(S) < q^b` for **every** `n` at `q = 2`.  The literal inequality
`ι(S) > q^b` fails on this infinite family.  However the loss is a bounded
constant `≥ 7/8`, it enters every lemma multiplicatively, and every
conclusion drawn from those lemmas is an **exponent** comparison
(`N₁/μ₁ > N/b`, `μ₁/k₁ ≥ b/K`) which a factor `8/7` cannot flip.  The note's
one-line dismissal is therefore *correct but under-argued*; the honest
statement is **“`ι ≥ (7/8)q^b` at `q = 2`, and all uniform lemmas are
exponent-level, so the constant is absorbed.”**  Recommended as a footnote.
Everywhere `ι(S)` is used as an **upper** bound (the orbit floor's RHS) the
smaller value is strictly conservative, exactly as the note says.

The other three exceptional rows are *above* `q^b` and cause no issue:
`m(Ω₇(3)) = 351 > 243`, `m(PΩ⁺₈(2)) = 120 > 64`, `m(PΩ⁺₈(3)) = 1080 > 729`.
GAP `Maxes` reconfirm all four, and confirm `PΩ⁻₈(2)`: `[119,136,765,…]`
— `119 = [S:P₁]`, **no** exception, as the note states.
