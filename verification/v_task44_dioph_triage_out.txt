==============================================================================
PART B -- the points at infinity: WHERE Sec.4ap's obstruction does and
          does not bite
==============================================================================
row1  S4  f = q^3+q^2+q+1          plane model of degree 3:
      -Q^3*cs - Q^2*Z*cs - Q*Z^2*cs - Z^3*cs + M^3 - M*Z^2
      F|_{Z=0} = -Q^3*cs + M^3
      => M^3 = c Q^3: rational points at infinity exist iff c is a
         cube.  c = 6*l**f1 is a cube for some l*, but at l* = 1
         (the only value the S4 row can take) c = 6 is not, which
         is exactly the Sec.4ap obstruction -- handled in
         v_task44_dioph_c6.sage.

row2  L3  f = q^2+q+1              plane model of degree 3:
      -Q^2*Z*cs - Q*Z^2*cs - Z^3*cs + M^3 - M*Z^2
      F|_{Z=0} = M^3
      => M^3 = 0: ONE point (1:0:0), with the line Z=0 meeting the
         cubic there to order 3 -- a RATIONAL INFLECTION.  Hence the
         pole divisor of q is 3*O with O rational: integrality is
         Weierstrass integrality and E.integral_points() APPLIES,
         for EVERY c.  (Sec.4ap's obstruction does NOT occur here.)

row3  L5  f = q^4+q^3+q^2+q+1      plane model of degree 4:
      -Q^4*cs - Q^3*Z*cs - Q^2*Z^2*cs - Q*Z^3*cs - Z^4*cs + M^3*Z - M*Z^3
      F|_{Z=0} = -Q^4*cs
      => c Q^4 = 0: the unique point at infinity is (0:1:0), and it
         is a smooth point (dF/dZ = M^3 there).  The model is a
         PLANE QUARTIC, genus 3, non-hyperelliptic, with a rational
         point -- but no algorithm for its integral points.

==============================================================================
PART D -- how much n-range does 'close all l* <= L' actually buy?
==============================================================================
Row 2 (L3).  The R1 spectral gap gives q >= f1*(n-3), hence
     C(n,3) = l* f1 (q^2+q+1) > l* f1^3 (n-3)^2,
     l* < n(n-1)(n-2) / (6 f1^3 (n-3)^2)  <  n/6   (f1 >= 1, n >= 10).
     closing l* <= 10       covers only n <= 60        
     closing l* <= 100      covers only n <= 600       
     closing l* <= 1000     covers only n <= 6000      
     closing l* <= 10000    covers only n <= 60000     
     closing l* <= 100000   covers only n <= 600000    
     closing l* <= 1000000  covers only n <= 6000000   
   The existing exact scan (v_task38/v_task41) already covers n <= 2e7
   COMPLETELY IN q AND l*.  So closing the family curve-by-curve up to
   l* <= L is strictly WEAKER than the scan unless L > 3.3e6, i.e. more
   than three million Mordell-Weil computations on curves with
   coefficients of size 48c^4 ~ 1e30.  The per-l* elliptic-curve route
   is NOT competitive; rows 2 and 3 need a uniform-in-l* argument.

Row 3 (L5).  l* is provably free (v_task41 Sec.1.3); the same count
applies with q^2 >= n-3, giving l* < n^3/(6 f1 (n-3)^2) < n/6 as well.

==============================================================================
PART E -- p-part refinement of the l* range (Lemma R1-p)
==============================================================================
For S* of Lie type over F_{p^f} with N positive roots, |S*|_p = p^{fN}
and |Q| divides n!/2, so  l* f N <= v_p(n!) < n/(p-1).
Row 2 (L3, N = 3, f >= 2): with q = p^f >= f1(n-3),
     3 l* f < n / (p-1),   p >= (f1 (n-3))^(1/f),
   so   l* < n^(1-1/f) / (3 f f1^(1/f)).
   f = 2: l* < sqrt(n)/6 ; f = 3: l* < n^(2/3)/9 ; and since
   p >= 2 forces f <= log2(f1 n) + 1, uniformly l* = O(n/log n).
Row 3 (L5, N = 10, f >= 1): 10 l* f <= v_p(n!) and q^2 >= n-3 give
     l* < n^(1-1/(2f))/(10 f) -- again unbounded.
CONCLUSION: no proven bound makes l* finite.  Rows 2 and 3 are open
families; row 1 is a single curve and is settled in v_task44_dioph_c6.
