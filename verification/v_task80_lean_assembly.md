## 1. The `Prop`

```lean
/-- `n·e_{(H,hH')}` is integral, said without mentioning `ℚ`. -/
def IsolatingValue (H : Subgroup G) (h : H) (n : ℕ) : Prop :=
  ∃ x : DRing G, DRing.species H h x = (n : ℂ) ∧
    ∀ (K : Subgroup G) (k : K), DRing.species K k ≠ DRing.species H h →
      DRing.species K k x = 0

def BoltjeIntegralityFor : Prop :=
  ∀ (H : Subgroup G) (h : H) (n : ℕ),
    IsolatingValue H h n ↔
      Nat.card (pairNormalizer H (h : G)) ∣ n * Nat.card ↥⁅H, H⁆

def BoltjeIntegrality : Prop :=
  ∀ (G : Type u) [Group G] [Fintype G], BoltjeIntegralityFor G
```

i.e. *the isolating values at the pair `(H, hH')` are exactly the
multiples of the index `(N_G(H,hH') : H')`*, in division-free form.

No fully-fused qualifier is needed: fusion enters only later, through
`fullyFused_of_intPoint'` inside `conductorPairDictionary'`.

### Why one `Prop` and not two

`boltjeIntegralityFor_of` proves the `Prop` is *exactly* Müller's two
halves:

```lean
theorem boltjeIntegralityFor_of
    (hW : ∀ H h n, n * |H'| = |N_G(H,hH')| → IsolatingValue H h n)
    (hL : ∀ H h n, IsolatingValue H h n → |N_G(H,hH')| ∣ n * |H'|) :
    BoltjeIntegralityFor G
```

* `hW` is Boltje's integrality congruence at the **single** value
  `n₀ = (N_G(H,hH') : H')`; the general `←` direction follows from it by
  scaling the witness (`IsolatingValue.mul_left`: `x ↦ (m : DRing G) * x`)
  together with `|H'| ∣ |N_G(H,hH')|`
  (`card_commutator_dvd_card_pairNormalizer`).
* `hL` is Müller's coefficient computation.

`hL` is genuinely *not* derivable from `hW` with the machinery of
§6–§11: the sharpest unconditional relation available is §8's

```
|H| · |N_G(H,h₀H')|  ∣  n · |H'| · |N_G(H)|      (card_mul_card_pairNormalizer_dvd)
```

which is short of `|N_G(H,h₀H')| ∣ n·|H'|` by exactly the factor
`(N_G(H) : H)` — the blind spot v_task77 identified (invisible to the
`H`-column of the species table, twisted or not).  Bundling both halves
into one `iff` is therefore the honest minimal packaging: it is one named
statement, of the shape "the ideal of isolable values is generated by the
index", whose two implications are the two pieces of mathematics Müller
cites and does not (in the `←` case) prove.
